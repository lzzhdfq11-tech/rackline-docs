Cart, PO numbers, CSV export and quotes

The Rackline cart is set up for business orders. Buyers can add a purchase order (PO) number and an order note, download the cart as a CSV file or send it as a quote request, and then check out with Shopify. You choose between a side panel cart and a full Order review page.

Cart type

Theme settings → Cart → Cart type:

  • Side panel (default): adding to the cart opens a panel with the order lines, quantities, totals and a checkout button. A Review order link goes to the cart page.
  • Cart page: adding to the cart goes straight to the cart page.

The cart page is titled Order review. It lists each line with image, SKU, product, unit price, quantity (with quantity rules) and line total, and has a summary column with totals, the PO number, the order note, checkout and the quote request. Lines can be removed one by one, or all at once with Clear order after a confirmation.

Purchase order number

  • Show purchase order number field (on by default) adds a “PO number” field to the Order review page.
  • The value is saved as a cart attribute named “PO number” and appears on the order in your admin.
  • Require purchase order number (off by default) stops checkout until the field is filled in, with the message “Enter a PO number before checking out.” In side panel mode, the panel then links to “Review order and add PO number”.

Order note

Show order notes adds an “Order note” field for delivery instructions or other details. Shopify saves it with the order.

Download the cart as CSV

With Allow cart download as CSV on, the Order review page has a Download CSV button. Buyers use it to attach the order to an internal purchase request. The file is created in the browser and named order-YYYY-MM-DD.csv.

Columns in the cart CSV file
ColumnContent
SKUVariant SKU
ProductProduct title
VariantVariant title
QuantityQuantity in the cart
Unit pricePrice per unit
Line totalLine price
CurrencyCart currency code

The file is UTF-8 encoded for spreadsheet apps, and values that start with characters such as = are written as text, so spreadsheets do not treat them as formulas.

Request a quote

With Theme settings → Pricing and trade → Allow quote requests from the cart on (default), the Order review page has a Request a quote button. It opens a form with name, email, company, phone and message. The request is sent through Shopify’s contact form to your store email with the subject “Quote request” and a list of the cart lines (SKU, product, quantity and line price). The buyer’s cart stays as it is. You reply with a quote, for example as a draft order from your admin.

Checkout

  • Show accelerated checkout buttons shows Shopify’s accelerated checkout buttons in the cart. The product page has its own setting in the Buy buttons block. The buttons follow the theme’s button shape.
  • For B2B buyers, the cart notes that payment terms for their company account, such as net terms, are applied at checkout.
  • The cart summary shows discounts and states that taxes and shipping are calculated at checkout (or that taxes are included).
  • When prices are shown to signed-in customers only, guests see a sign-in link instead of prices and the checkout button.
