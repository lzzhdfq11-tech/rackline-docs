Collections, filters and SKU search

Rackline lists products as a table or as a grid on collection and search pages. The table view puts stock, price and a quantity field with an Add button on every row, multi-variant products open a variant order table, and filters and sorting update the list without a full page reload.

Table view

The table view is built for buyers who scan many rows. Each row shows:

  • the image, title, SKU and brand;
  • availability (following the stock settings);
  • the price, with compact volume pricing when Show volume pricing in lists is on;
  • a quantity field and Add button for single-variant products, or an Options (n) button for products with variants.

On phones, rows keep the quantity field and Add button side by side so buyers can order without opening the product.

Grid view

The grid view shows product cards. In the Rackline preset the cards look like shelf bin labels: a label strip with the aisle code and the SKU (or the product’s bin location), the image, title, stock and price, the compact price ladder, a decorative barcode and a quantity and add bar. Card options are in Theme settings → Product lists: image ratio, show brand, show SKU and show second image on hover.

Switching between table and grid

The default view comes from Theme settings → Product lists → Default collection view (table in the Rackline and Ledger presets, grid in Crate). When Show table / grid toggle is on in the section, shoppers can switch views, and their choice is remembered in their browser for later visits.

Filtering, sorting and pages

  • Filters appear in a sidebar on desktop and in a panel on phones. Choose which filters appear (availability, price, product type, vendor, options, metafields) in Shopify’s Search & Discovery app.
  • Selected filters show as removable chips with Clear all; the price filter takes a from and to amount.
  • Filtering and sorting update the product list in place and keep the page address in sync, so the back button and shared links work.
  • The result count is announced to screen readers.
  • Pages are numbered. Settings: products per page, filter groups expanded by default, enable filtering and enable sorting.

Options: the variant order table from a list

For products with several variants, the Options (n) button opens a dialog with the product’s variant order table. Buyers enter quantities for several variants, see the subtotal and add them all at once, without leaving the collection. A link opens the full product page. The dialog’s section, Quick order options, has settings for showing the image and brand.

Predictive search

The header search field shows suggestions as the shopper types: products, collections, pages, articles and query suggestions. Product suggestions also match variant SKUs and barcodes, and show the SKU (setting Show SKUs in suggestions) and the price. Shoppers browse the suggestions with the arrow keys. Turn suggestions on or off with Theme settings → Search → Show search suggestions.

Search results page

Search results use the same table or grid views, filters and sorting as collections. Settings include results per page, the view toggle, quantity and add to cart, and a link to matching pages and articles. When nothing matches, the page shows search tips, such as searching by the full SKU from an invoice.

Collection list page and aisle codes

The collection list page (all collections) shows your collections as a table or as tiles, with an optional product count and image, and a Find a collection field that filters the list as you type. You can show all collections or choose specific ones, sorted alphabetically or in the order you list them.

Each collection carries an aisle code and color band: the collection’s custom.zone_code metafield when it has one, otherwise a position code (A1, A2, B1 …). The same codes appear in the menu drawer, the Collection list section on the home page and on product labels. On desktop, the main menu shows aisle letters on top-level items. See Add aisle codes.

Brand index

The Brand index section (template brands) shows up to 24 featured brand cards with a logo, short text and link, followed by an A–Z directory of every product vendor in your store with a jump-to-letter row. Each vendor links to its product list.
